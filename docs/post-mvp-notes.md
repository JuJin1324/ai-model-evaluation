# Post-MVP 평가 확장 메모

> MVP 평가 진행 중 발견된 관찰 사항과 향후 평가에 반영할 항목을 기록한다.

---

## 도구 선택 능력 (Edit vs Write)

**관찰 배경:** Gemini CLI 평가 시 발견된 현상

**현상:**
- 기존 파일의 일부를 수정해야 하는 상황에서 `Edit` 도구 대신 `Write` 도구를 사용
- 대화를 통해 합의한 내용을 반영할 때, 합의된 부분만 Edit으로 고쳐야 하는데 파일 전체를 Write로 덮어씀
- 결과적으로 마지막 합의 내용만 남고 기존 내용이 유실됨

**평가 의미:**
- 도구의 용도를 정확히 구분하는 능력 — `Edit`(부분 수정) vs `Write`(전체 생성)
- 기존 파일의 안전성 (문서 안전성 평가 항목과 연결)
- 맥락에 따른 적절한 도구 선택 판단력

**향후 평가 반영 방안:**
- 루브릭에 "도구 선택 적절성" 항목 추가 검토
- 관찰 체크리스트에 "기존 파일 수정 시 Edit/Write 구분 사용" 항목 추가 검토
- 의도적으로 기존 파일 수정이 필요한 태스크를 평가 프롬프트에 포함하는 방안 검토
