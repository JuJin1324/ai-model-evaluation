3. 선택지에 없는 내용을 직접 입력 가능했고, 추천 prefix가 달린 선택지는 판단에 도움이 됨.
4. scope-mvp에서 mermaid 대신 ASCII 다이어그램 추천이 아쉬웠음 (보편성 관점에서 이해는 됨).
