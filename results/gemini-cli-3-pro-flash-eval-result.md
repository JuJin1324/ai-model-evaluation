## 정성 소감

1. Gemini 자체 내장 Skill Creator/검증/설치 프로세스가 체계적. 스킬 관리 인프라 면에서 가장 성숙한 모습을 보여줌.
2. .gemini/skills/에 설치하는 과정이 있어 Codex처럼 .claude/skills/를 오염시키는 문제가 자연스럽게 방지됨.
3. 다만 SKILL.md 내용이 매우 축약되고 보편적. "설명을 걷어내고 행동 지침만 남겼다"는 논리를 제시했으나, 실제로 스킬을 실행해보지 않아 이 접근이 정말 효과적인지는 미확인.
4. 스킬 통합 유지에 대한 3가지 논거(맥락 유지, 트리거 충돌 방지, 철학적 사고 연속성)가 매우 설득력 있었음. 특히 "분절되지 않은 흐름"이라는 관점이 인상적이어서 추가 분리를 요청하지 않고 멈춤.
5. 영어로 답변하는 경우가 자주 관찰됨. 한국어 지원 안정성에 아쉬움.
6. Claude Code Sonnet 4.6의 Argument 기반 워크플로우 분기와 대비하면, Gemini는 하나의 워크플로우도 제대로 커버할 수 있을지 우려가 생길 정도로 간소화.
