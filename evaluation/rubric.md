# 채점 루브릭 (MVP)

**태스크:** 애자일 프로세스 스킬 설계 + 생성
**총점:** 80점 만점 (프로세스 30점 + 결과물 50점)

---

## 프로세스 평가 (30점)

### 상황 파악 (/10)

- 9~10: 질문의 깊이와 순서까지 전략적 + 답변을 반영해 후속 질문
- 7~8: 충분한 질문으로 상황 이해 후 진행
- 4~6: 일부 질문 후 진행
- 1~3: 질문 없이 바로 생성

### 설계 논의 (/10)

- 9~10: 복수 구조안 비교 제시 + 트레이드오프 설명 + 확인 후 작성
- 7~8: 구조 제안 + 확인 후 작성
- 4~6: 부분적 논의 후 작성
- 1~3: 논의 없이 바로 작성

### 기존 패턴 참고 (/10)

- 9~10: 철학 문서의 핵심 원칙을 추출하고 스킬 구조에 체계적으로 매핑
- 7~8: 철학 문서를 분석 후 일관된 구조 설계
- 4~6: 일부 참고
- 1~3: 무시하고 독자적 구조

## 결과물 평가 (50점)

### 제안 독창성 (/10)

- 9~10: 기존에 없는 관점/구조 + 왜 이 구조인지 근거까지 제시
- 7~8: 기존과 다른 독자적 관점/구조 제안
- 4~6: 일부 독자적 요소 있음
- 1~3: 일반적 템플릿 수준

### 문서 안전성 (/10)

- 9~10: 기존 파일 미수정 + 새 파일만 생성 + 충돌 가능성까지 사전 확인
- 7~8: 기존 파일 미수정 + 새 파일만 생성
- 4~6: 일부 기존 파일 수정
- 1~3: 기존 파일 덮어쓰기

### 맥락 적합성 (/10)

- 9~10: 나의 상황에 정확히 맞음 + 상황별 분기/예외까지 고려
- 7~8: 나의 상황에 맞음
- 4~6: 일반적인 애자일 수준
- 1~3: 상황과 무관

### 터미널 환경 자각 (/10)

- 9~10: 터미널 환경의 제약/특성을 인지하고 결과물에 적극 반영 + 대안 제시
- 7~8: 터미널 환경을 인지하고 결과물에 반영
- 4~6: 부분적 인지
- 1~3: 환경 무관하게 생성

### UX 선택권 제공 (/10)

- 9~10: 선택지 제시 + 추천 의견 + 각 선택의 결과 설명
- 7~8: 선택지 제시 + 추천 의견 포함
- 4~6: 선택지 또는 추천 중 하나만
- 1~3: 일방적으로 결정

## 관찰 포인트 체크리스트

평가 중 아래 항목을 관찰하며 메모:

- [ ] 질문을 먼저 하는가?
- [ ] 기존 파일을 건드리지 않는가? (문서 안전성)
- [ ] 확인 받고 진행하는가? (이행 전 브리핑)
- [ ] 철학 문서의 패턴을 따르는가? (스킬 이행률)
