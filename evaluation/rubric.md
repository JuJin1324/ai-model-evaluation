# 채점 루브릭 (MVP)

**태스크:** 애자일 프로세스 스킬 설계 + 생성
**총점:** 30점 만점 + 비용 별도 비교

---

## 프로세스 평가 (15점)

| 항목 | 5점 | 3점 | 1점 |
|------|-----|-----|-----|
| **상황 파악** | 충분한 질문으로 상황 이해 후 진행 | 일부 질문 후 진행 | 질문 없이 바로 생성 |
| **설계 논의** | 구조 제안 + 확인 후 작성 | 부분적 논의 후 작성 | 논의 없이 바로 작성 |
| **기존 패턴 참고** | 철학 문서를 분석 후 일관된 구조 설계 | 일부 참고 | 무시하고 독자적 구조 |

## 결과물 평가 (15점)

| 항목 | 5점 | 3점 | 1점 |
|------|-----|-----|-----|
| **스킬 완성도** | 바로 사용 가능한 수준 | 수정 필요하지만 골격 있음 | 사용 불가 |
| **시각화** | 워크플로우 다이어그램 포함 + 렌더링 가능 | 다이어그램 있으나 불완전 | 다이어그램 없음 |
| **맥락 적합성** | 나의 상황에 정확히 맞음 | 일반적인 애자일 수준 | 상황과 무관 |

## 관찰 포인트 체크리스트

평가 중 아래 항목을 관찰하며 메모:

- [ ] 질문을 먼저 하는가?
- [ ] 기존 파일을 건드리지 않는가? (문서 안전성)
- [ ] 머메이드 다이어그램을 포함하는가?
- [ ] 워크플로우를 시각화로 제안하는가?
- [ ] 확인 받고 진행하는가? (이행 전 브리핑)
- [ ] 철학 문서의 패턴을 따르는가? (스킬 이행률)
