## 실시간 메모

시작 전
1. 첫번째로 봐야하는 것은 스킬을 하나만 제안할지 여러개의 스킬을 나눠서 제안할지이다.

시작 후
1. 사용 맥락: 새 프로젝트인지 기존 프로젝트에 도입하는지 구분을 요구하며, 스프린트를 계획까지 해줄지, 
회고까지 해줄지 MVP 단위까지 해줄지 제안하였으며, 사용자의 범위(개인/팀)까지 물어보았음. 다만 불안했던 것은 둘 다라는 선택지를 통해서 과연 좋은 결과가 나올지였음.
2. 처음 제안한 스킬은 1개(agile-2w1h)였음. 스킬을 1개로 제안한 이유에 대해서 묻자 2개로 분리해주었음.(2w1h-discovery, sprint-mvp)
하지만 그럼에도 스킬이 부족해보임. 다만 계속해서 선택지를 줘서 개선하기 용이하였음.
3. 선택지에 없는 내용을 내가 적을 수 있어서 이것도 용이했음. 그리고 가끔 선택을 어떻게 해야할지 모르는 선택지에는 추천 prefix 가 달려있어서 선택이 용이하였음.
4. scope-mvp 스킬에서 "전체 범위를 ASCII 다이어그램"로 mermaid 가 아닌 ASCII 다이어그램 추천이 아쉬웠음.(다만 이건 mermaid 보다 ASCII 가 조금 더 보편적이라 생각해서 그런듯)
5. mvp 를 모두 완료한 다음에는 어떻게 프로젝트가 진행되는지 물어봤을 때 회고 이후 범위가 남아있으면 다시 scope-mvp 를 통해서 계속 진행과 Why/what 이 바뀌었으면 2w1h-narrative 를 통해
서사부터 재정의로 가이드를 준게 괜찮았음.
